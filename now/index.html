What I'm doing now

A snapshot of where my attention is this semester. Updated when it changes, not on a schedule.

Updated September 22, 2026 Richardson, TX A /now page

Building

  • NovaSearch, milestone 2. Milestone 1 shipped hybrid keyword and semantic search with a deterministic bag-of-words embedding baseline. The next step is a real model-backed embedding provider behind the same interface, with embedding versioning so a model change can re-index safely.
  • Distributed Job Scheduler, milestone 2. The durable core is done: SKIP LOCKED claims, leases, heartbeats, crash recovery, fenced attempt history. Next up are recurring schedules and job dependencies on top of it.
  • Distributed Object Storage. Reads already survive a node loss. The missing piece is repair: rebuilding a lost node's replicas so redundancy is restored instead of just tolerated.
  • Small tools when coursework needs them. K-Map Looper and the Logic Diagram Tool both came out of digital-logic assignments. If another class has a tedious, repetitive drawing or formatting step, it will probably get the same treatment.

Studying

Fall 2026 at The University of Texas at Dallas, on track to graduate in December 2027. Outside class I am going deeper on the things the projects keep running into: PostgreSQL locking and isolation semantics, Kafka delivery guarantees, and how to write tests that force a specific interleaving instead of hoping for one.

Writing

I just started writing up the mechanisms behind the commerce platform, one at a time. The outbox and idempotent-consumer posts are up. The next one I want to write is about the latch-driven concurrency tests, because they were the hardest part to get right and the part I learned the most from.
