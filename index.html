01 · About

About

I'm a Computer Science student at The University of Texas at Dallas, graduating Fall 2027 and looking for a Summer 2027 software engineering internship. What interests me is the part of backend work that only shows up under load or failure: getting exactly-once effects on top of at-least-once delivery, holding a transaction's guarantees across a service boundary, and keeping concurrent writers from quietly losing each other's updates.

Most of what I know came from building the systems below and then breaking them on purpose — stopping a storage node mid-request, pointing two publisher replicas at one table, racing two workers for the same job. The posts under Writing are what those experiments taught me.

Applied AI arrives the same way round: NovaSearch is a retrieval problem first — keyword and vector search over one database, fused and cached — and an AI problem second.

Distributed Job Scheduler

Milestone 1

Java · Spring Boot · PostgreSQL · Docker

A background-job platform where competing workers coordinate through PostgreSQL row locks alone — no broker, no coordination service.

  • REST API, immediate and delayed jobs, cancellation
  • Claims via SKIP LOCKED, leases, heartbeats, crash reaper
  • Bounded retries and fenced attempt history
  • 43 tests including two-worker claim races, in CI

Next cron schedules, dependencies, priorities

Distributed Object Storage

Milestone 1

Java · Spring Boot · PostgreSQL · Docker

Objects split into chunks and replicated to two of three storage nodes, SHA-256-verified end to end, and still readable through a node failure.

  • Coordinator plus dumb storage nodes, 1 MiB chunks
  • Deterministic placement, replication factor 2
  • Corrupt or dead replica falls through to the next
  • End-to-end suite stops a real node mid-test, in CI

Next repair and re-replication, consistent hashing

K-Map Looper

Live

HTML · Canvas · Vanilla JavaScript · one file, no dependencies

For digital-logic coursework. Fill a 2, 3, or 4-variable Karnaugh map, click the cells in each group, and it draws the loops cleanly — wrap-around included — then exports a PNG for a typed submission. It draws rather than solves, because spotting the groupings is the exercise.

Logic Diagram Tool

Live

HTML · SVG · Vanilla JavaScript · one file, no dependencies

Type a Boolean equation with up to four inputs and it draws the gate diagram in standard ANSI symbols, generates the full truth table, and exports both as PNG or SVG for a lab report. Parses the usual notations, folds NOT-over-AND/OR/XOR into single NAND/NOR/XNOR gates, and routes the wires with proper junction dots.
